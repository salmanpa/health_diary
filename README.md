# Health Diary

Минимальная база календаря здоровья на SQLite. Она хранит:

- питание с калориями и БЖУ;
- тренировки;
- сон;
- дневные заметки и сводные показатели.

## Быстрый старт

Создать локальную базу с начальными данными:

```bash
./scripts/init_db.sh
```

База появится в `data/health_diary.sqlite3`. Она считается локальным рабочим
файлом и не коммитится: структура и исходные данные хранятся в SQL-файлах.

Посмотреть календарную сводку:

```bash
sqlite3 -header -column data/health_diary.sqlite3 \
  "SELECT * FROM daily_health_summary ORDER BY diary_date DESC;"
```

## Начальные данные

За 4 августа 2026 года внесены:

- утренний бег — 5,15 км за 30 минут, средний темп примерно 5:50 мин/км;
- сон — 5,5 часа;
- завтрак — 610 ккал, Б/Ж/У 35/28/61 г;
- обед — 825 ккал, Б/Ж/У 37,5/42,5/40 г;
- перекус — 190 ккал, БЖУ не указаны;
- ужин — 600 ккал, Б/Ж/У 46/34/22,5 г.

Итого — примерно 2225 ккал и не менее 118,5/104,5/123,5 г Б/Ж/У. Итоговые
БЖУ неполные, поскольку для двух яблок известна только калорийность.
