# Health Diary

Минимальная база календаря здоровья на SQLite. Она хранит:

- питание с калориями и БЖУ;
- дневные основы питания: мясо, курица и рыба;
- тренировки;
- шахматные партии и победы;
- сон;
- оценку дня по пятибалльной шкале;
- расходы в рублях по категориям;
- дневные заметки и сводные показатели.

Проект также содержит автономную месячную страницу аналитики и правила
бережной оценки еды по фотографиям.

## Быстрый старт

Создать локальную базу с начальными данными:

```bash
./scripts/init_db.sh
```

База появится в `data/health_diary.sqlite3`. Она атомарно пересобирается из SQL,
считается локальным рабочим файлом и не коммитится: структура и исходные данные
хранятся в SQL-файлах.

Посмотреть календарную сводку:

```bash
sqlite3 -header -column data/health_diary.sqlite3 \
  "SELECT * FROM daily_health_summary ORDER BY diary_date DESC;"
```

Собрать страницу аналитики:

```bash
./scripts/build_dashboard.sh
```

Затем открыть `dashboard/index.html` в браузере. Страница работает без сервера
и внешних библиотек; текущий день со статусом `in_progress` не попадает в
средние полного дня.

питания этого дня — курица и рыба.

составили 430 ₽ за напиток (категория не указана).

История продолжена до 8 августа. Дни 4–7 августа помечены завершёнными, 8
августа — заполняемым. Актуальные суммы лучше смотреть в
`daily_health_summary`, а месячные — в `monthly_health_summary` или на странице
аналитики.
