# Health Diary

Минимальная база календаря здоровья на SQLite. Она хранит:

- питание с калориями и БЖУ;
- состав каждого приёма пищи и оценку клетчатки, витаминов и минералов;
- дневные основы питания: мясо, курица и рыба;
- тренировки;
- шахматные партии и победы;
- сон;
- оценку дня по пятибалльной шкале;
- дневные заметки и сводные показатели.

Проект также содержит автономную месячную страницу аналитики и правила
бережной оценки еды по фотографиям.

## Быстрый старт

Создать локальную базу с начальными данными:

```bash
./scripts/init_db.sh
```

База появится в `data/health_diary.sqlite3`. Она атомарно пересобирается из
`db/schema.sql`, `db/seed.sql` и `db/nutrition_components.sql`, считается
локальным рабочим файлом и не коммитится. Последний файл хранит восстановленный
состав блюд, веса компонентов, уверенность оценки и ссылки на справочные
профили продуктов.

Посмотреть календарную сводку:

```bash
sqlite3 -header -column data/health_diary.sqlite3 \
  "SELECT * FROM daily_health_summary ORDER BY diary_date DESC;"
```

Собрать страницу аналитики:

```bash
./scripts/build_dashboard.sh
```

Затем открыть `dashboard/index.html` в браузере. Страница работает без сервера
и внешних библиотек; текущий день со статусом `in_progress` не попадает в
средние полного дня. В нём есть дневные калории и БЖУ, сон, время и число
тренировок, оценка расхода энергии, а также клетчатка, витамины и минералы по
дням. Дашборд является ручным аналитическим снимком: после обычных записей
дневника он не пересобирается автоматически. Обновляйте его только отдельным
запуском команды выше, когда нужен новый срез.

Микронутриенты рассчитываются по оценённым составляющим блюд и справочным
данным USDA FoodData Central. Эти значения описывают примерное поступление с
едой и не являются диагнозом дефицита; неизвестные соусы, соль и части рецептов
сохраняются как пробелы, а не как нулевое потребление.

## Как вносить данные

Короткие шаблоны для сна, еды, бега, зала и завершения дня находятся в
[`docs/quick-entry.md`](docs/quick-entry.md). Подробный аудит текущих данных,
варианты мобильного ввода и рекомендуемая архитектура Telegram-бота описаны в

## Текущие данные

История продолжена до 8 августа 2026 года. Дни 4–7 августа помечены
завершёнными, 8 августа — заполняемым. Дневные показатели находятся в
`daily_health_summary` и `daily_nutrient_summary`, месячные — в
`monthly_health_summary`, а визуальный срез — на странице аналитики.
